# 📋 Log de Capturas Procesadas — SC-200

> [!info] ¿Para qué sirve este archivo?
> Este log registra todas las capturas de pantalla del curso SC-200 que ya han sido curadas hacia el vault. Se usa para **no reprocesar** imágenes en tandas futuras.
>
> **Flujo de trabajo estándar:**
> 1. El usuario añade capturas `.png` a `C:\Users\mirau\Documents\certs cursos\`
> 2. Al iniciar una sesión de curación, el agente lista los `.png` de esa carpeta y los cruza con este log
> 3. Solo se curan las capturas que **no aparecen** en la tabla de abajo
> 4. Tras curar cada tanda, el agente añade las nuevas filas a este log antes de finalizar
